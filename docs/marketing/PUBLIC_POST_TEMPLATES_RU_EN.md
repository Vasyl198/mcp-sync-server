## Template 3 - Technical Deep Dive (RU)

**Тема:** Как работает MCP Security Gate (коротко)

1. Intake: цель + контекст + политика  
2. Act: запуск инструментов (детерминированно)  
3. Verify: проверка evidence и quality/security сигналов  
4. Verdict: GO/NO-GO + причины + next steps

Почему это важно:
- меньше “галлюцинаций”
- больше воспроизводимости
- понятный путь к remediation

CTA:  
Если нужен пилот под ваш репозиторий/сервис — пишите в issues `Pilot Request`.
