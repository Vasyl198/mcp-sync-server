# Launch Day Checklist

Date: `YYYY-MM-DD`

## Pre-Launch (30-60 min)

1. Verify repository health:
   - `main` is default branch
   - CI on latest commit is green
   - Release `v0.1.0` is published
2. Verify public assets:
   - README badges render correctly
   - Architecture diagram renders
   - Analysis snapshot images render
3. Verify intake:
   - Issue template `Pilot Request` is available
   - Labels and milestone are present

## Publish

1. Post #1 (RU): launch announcement
2. Post #2 (EN): launch announcement
3. Post #3 (tech): “How MCP Security Gate works”
4. Pin repository in GitHub profile

## Post-Publish (same day)

1. Reply to first comments/questions.
2. Convert serious interest to `Pilot Request` issue.
3. Open internal tracking record for every lead.

## 48h Follow-up

1. Publish mini-update:
   - what was improved after feedback
   - one concrete metric
2. Close at least one `good first issue` or roadmap item.
3. Publish first weekly progress report.
