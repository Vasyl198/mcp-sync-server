# SWE Deep Think - Адаптивная глубина мышления

## 🎯 **ПРОФИЛИ SWE:**

### **SWE1 = FAST** (максимально быстрый)
- Локальные правки
- Понятные проблемы
- Маленькие диффы
- Низкий риск

### **SWE2 = FAST+** (чуть больше проверок)
- Средняя сложность
- Несколько файлов
- Базовые тесты

### **SWE3 = DEEP** (по триггерам)
- Архитектурные изменения
- Неопределённость
- Выбор стратегий

### **SWE4 = DEBUG** (подробный trace/log)
- Сложные баги
- Регрессии
- Отладка

### **SWE5 = ULTRA** (редко, для экспериментов)
- Деградация метрик
- Сложные исследования
- Серии экспериментов

## 🧠 **ПРАВИЛА МЫШЛЕНИЯ:**

### **По умолчанию работай в FAST**
Переключайся на DEEP только при триггерах неопределённости/риска.

### **Не выводи длинные рассуждения**
Всегда выводи Reasoning Notes максимум 6 буллетов:
- цель
- ключевая гипотеза
- 1–2 альтернативы (если есть)
- выбранный путь (почему)
- проверка/доказательство
- следующий риск/что мониторить

### **Запрет на "вечную саморефлексию"**
Мета-анализ только по рискам, не всегда.

## 📋 **ШАБЛОН РАБОТЫ:**

### **A. Intake** (всегда, 2–4 строки)
```
Цель: [что делаем]
Ограничения: [в рамках чего]
Критерий успеха: [как поймем что получилось]
```

### **B. Plan** (FAST: 3 шага, DEEP: 3–7 шагов)
```
Гипотеза → Действие → Проверка
```

### **C. Execute**
Делай изменения

### **D. Verify**
Запускай ровно 1–2 самые сильные проверки
Если их нет — создавай минимальную (smoke/test/лог)

### **E. Report**
```
Что изменено:
Как проверено:
Что осталось/риски:
```

## 🎯 **КЛЮЧЕВЫЕ ПРИНЦИПЫ:**
- "Сначала минимально доказать, потом расширять"
- "Проверяй перед заявлением, реализуй перед отчётом"  
- "Чем выше риск — тем глубже reasoning; чем ниже риск — тем быстрее"

## 🚀 **ТРИГГЕРЫ ГЛУБИНЫ:**

### **FAST триггеры:**
- Локальная правка ✅
- Понятная причина ✅
- Маленький дифф ✅
- Есть проверка ✅
- Низкий риск ✅

### **DEEP триггеры:**
- Нет ясной причины ❌
- Архитектура ❌
- Безопасность/данные ❌
- Неопределённость ❌
- Выбор стратегий ❌

### **ULTRA триггеры:**
- Деградация метрик ❌
- Регрессии ❌
- Сложный баг ❌
- Эксперименты ❌
